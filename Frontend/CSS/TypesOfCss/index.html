Cascading Style Sheet

Inline CSS

Inline CSS woh CSS hoti hai jo directly HTML element ke andar style attribute ka use karke likhi jati hai.

Main ek Inline CSS hoon.

Internal CSS

Internal CSS ko HTML ke head tag ke andar style tag ke andar likha jata hai.

External CSS

External CSS ko ek separate CSS file mein likha jata hai aur HTML ke head tag ke andar link tag ke through connect kiya jata hai.
