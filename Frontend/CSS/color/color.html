Color Property

Color name se hum text ka color change kar sakte hain.

HEX color me hexadecimal value ka use karke color define kiya jata hai.

RGB color me red, green aur blue values ka use karke color banaya jata hai.

RGBA me RGB ke saath alpha value use karke transparency control kar sakte hain.

HSL me hue, saturation aur lightness ki help se color define kiya jata hai.

HSLA me HSL ke saath alpha value use karke transparency control kar sakte hain.
