Font Family

Main ek external font hoon aur mujhe Google Fonts se link tag ke through HTML ke head section me add kiya gaya hai.

Font size se hum text ka size chhota ya bada kar sakte hain.

Font weight se hum text ko normal, bold ya extra bold bana sakte hain.

Font style se hum text ko normal ya italic style me dikha sakte hain.

Font variant se text ko small caps jaise different format me dikha sakte hain.

Line height text ki lines ke beech ka vertical space control karta hai.

Letter spacing letters ke beech ka horizontal space control karta hai.

Word spacing words ke beech ka extra space control karta hai.

Text align ki help se hum text ko left, center, right ya justify kar sakte hain.

Text decoration ki help se hum text par underline, overline ya line-through laga sakte hain.

Text transform se hum text ko uppercase, lowercase ya capitalize kar sakte hain.

Text indent paragraph ki first line ko left side se specific distance tak move karta hai.

Text shadow ki help se hum text ke peeche shadow effect create kar sakte hain.
