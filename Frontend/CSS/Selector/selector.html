All Selectors

Element Selector

Main ek Element Selector hoon. Mujhe directly HTML elements ke saath use kiya jata hai, jaise p, h1, h2, div, etc.

Class Selector

Main ek Class Selector hoon. Mujhe class name ke saath use kiya jata hai aur CSS mein mujhe dot (.) ke saath select kiya jata hai.

ID Selector

Main ek ID Selector hoon. Mujhe unique element ko select karne ke liye use kiya jata hai aur CSS mein mujhe hash (#) ke saath select kiya jata hai.

Universal Selector

Main ek Universal Selector hoon. Mujhe page ke sabhi HTML elements ko select karne ke liye use kiya jata hai aur CSS mein mujhe asterisk (*) ke saath use kiya jata hai.
