Combinators

Combinators ka use HTML elements ke beech ke relationship ko define karne ke liye kiya jata hai.

Descendant Combinator

Parent ke andar jitne bhi matching child aur nested child elements honge, un sabhi par style apply hoga. Example: div p

Main ek nested p hoon.

Child Combinator

Child combinator sirf direct child element ko select karta hai. Nested child ya grandchild par style apply nahi hota. Example: .child > p

Main ek nested p hoon.

Adjacent Sibling Combinator

Ye selector kisi element ke turant baad aane wale sibling element ko select karta hai. Example: .sibling + p

Main ek nested p hoon.

General Sibling Combinator

Ye selector kisi element ke baad same parent ke andar aane wale sabhi matching sibling elements ko select karta hai. Example: .allsibling ~ p

Main ek nested p hoon.

Pseudo-Class

Pseudo-class ka use kisi element ki specific state ya position ko target karne ke liye kiya jata hai. Example: :hover, :first-child, :last-child

Main ek nested p hoon.
