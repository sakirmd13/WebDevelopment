HTML Entities

HTML entities are special codes used to display reserved characters, special symbols, and characters that cannot be easily typed directly in HTML. They usually begin with an ampersand (&) and end with a semicolon (;).

1. Less Than and Greater Than

The less-than (<) and greater-than (>) symbols are used to create HTML tags. If you want to display these symbols as text, you should use their HTML entities.

Example: 5 < 10 and 10 > 5

2. Ampersand

The ampersand symbol (&) is used to begin an HTML entity. To display an actual ampersand character, use the &amp; entity.

Example: HTML & CSS

3. Non-Breaking Space

The &nbsp; entity creates an extra space that the browser does not collapse. It is called a non-breaking space because it also prevents a line break at that space.

Example: Hello   World

4. Copyright Symbol

The &copy; entity displays the copyright symbol. It is commonly used in website footers to indicate ownership of original content.

Example: © 2026 Md Sakir

5. Registered Trademark

The &reg; entity displays the registered trademark symbol. It is used to represent a registered brand or trademark.

Example: Brand®

6. Trademark

The &trade; entity displays the trademark symbol. It is commonly used with brand names or products.

Example: MyBrand™

7. Euro Symbol

The &euro; entity displays the euro currency symbol. It is used when writing prices in euros.

Example: €100

8. Rupee Symbol

The &#8377; entity displays the Indian rupee symbol. It is useful when displaying prices in Indian currency.

Example: ₹500

9. Dollar Symbol

The dollar symbol can be written directly in HTML because it is not a reserved HTML character.

Example: $100

10. Degree Symbol

The &deg; entity displays the degree symbol. It is commonly used for temperature and angles.

Example: 30°C

11. Plus-Minus Symbol

The &plusmn; entity displays the plus-minus symbol. It is commonly used in mathematics and measurements.

Example: 10 ± 2

12. Multiplication Symbol

The &times; entity displays the multiplication symbol. It is useful when writing mathematical calculations.

Example: 5 × 4 = 20

13. Division Symbol

The &divide; entity displays the division symbol. It is commonly used in mathematical expressions.

Example: 20 ÷ 4 = 5

14. Check Mark

The &check; entity displays a check mark. It can be used to show completed tasks or successful actions.

Example: Task completed ✓

15. Heart Symbol

The &hearts; entity displays a heart symbol. It is commonly used in simple messages and decorative content.

Example: Made with ♥

16. Quotation Marks

The &quot; entity displays double quotation marks. It is useful when you need to show quotation marks as text inside HTML.

Example: "Hello World"

17. Apostrophe

The &apos; entity displays an apostrophe character. It can be used when writing contractions or possessive words.

Example: Sakir&apos;s Laptop

18. Copyright and Reserved Characters

HTML entities are especially useful for displaying characters that HTML normally treats as code. For example, writing &lt; displays < instead of starting an HTML tag.
