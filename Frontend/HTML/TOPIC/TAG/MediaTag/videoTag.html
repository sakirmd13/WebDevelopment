Video tag

This is a basic video tag. The src attribute specifies the location of the video file. The height and width attributes define the video's dimensions. Since the controls attribute is not used, the browser does not display playback controls.

Video tag with controls

This video tag includes the controls attribute. It allows users to play, pause, adjust the volume, and control the video playback using the browser's built-in controls.

Video tag with controls and muted

This video includes both controls and muted attributes. The controls attribute provides playback controls, while muted starts the video without sound. The muted attribute is useful when you want a video to play silently.

Video tag with controls, muted, and loop

This video includes controls, muted, and loop attributes. The controls attribute provides playback controls, muted starts the video without sound, and loop automatically restarts the video when it reaches the end.
