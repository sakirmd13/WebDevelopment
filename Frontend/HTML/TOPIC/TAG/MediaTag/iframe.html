Basic Iframe Tag Without Fullscreen

This is a basic iframe tag used to embed a YouTube video inside the webpage. The width and height attributes define the size of the iframe. The src attribute specifies the URL of the content being embedded, and the title attribute describes the embedded content. Since the allowfullscreen attribute is not used, the fullscreen option is not enabled through this iframe.

Iframe Tag with Fullscreen

This iframe embeds a YouTube video with additional permissions and fullscreen support. The allow attribute specifies which browser features the embedded content can use. The allowfullscreen attribute allows the video to be displayed in fullscreen mode. The frameborder attribute is an older attribute used to control the iframe border.

Map with Iframe

This iframe embeds a Google Maps location inside the webpage. The src attribute contains the Google Maps embed URL. The width and height attributes define the map size, while the style attribute removes the iframe border. The allowfullscreen attribute allows fullscreen viewing, loading="lazy" delays loading until the map is near the visible area, and the referrerpolicy attribute controls how much referrer information is sent when loading the map.
