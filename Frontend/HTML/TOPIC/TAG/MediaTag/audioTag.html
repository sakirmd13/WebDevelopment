Audio tag

This is a basic audio tag. The src attribute specifies the location of the audio file. Since the controls attribute is not used, the browser does not display audio playback controls. The text "play me" acts as fallback content for browsers that do not support the audio element.

Audio tag with controls

This audio tag includes the controls attribute. It displays built-in audio controls, allowing users to play, pause, adjust the volume, and control audio playback.

Audio tag with controls and muted

This audio tag includes both controls and muted attributes. The controls attribute provides playback controls, while muted starts the audio without sound. The user can unmute the audio using the volume control.

Audio tag with controls, muted, and loop

This audio tag includes controls, muted, and loop attributes. The controls attribute provides playback controls, muted starts the audio without sound, and loop automatically restarts the audio when it reaches the end.
