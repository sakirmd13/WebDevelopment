Image Tag

This image uses an HTTPS link in the src attribute. The browser downloads the image from the specified online URL and displays it on the webpage. The alt attribute provides alternative text that describes the image if it cannot be displayed.

Image Tag with Height and Width

This image uses an HTTPS link along with height and width attributes. The height and width attributes set the displayed image dimensions to 100 pixels by 100 pixels. These attributes help control the image size on the webpage.

Image Tag Using a Local Image

This image uses a local file path in the src attribute. The browser looks for the image inside the image folder, which is located in the current project directory. The alt attribute describes the image if it cannot be displayed.

Local Image with Height and Width

This image uses a local file path along with height and width attributes. The browser loads the image from the project folder and displays it at 100 pixels wide and 100 pixels high.
