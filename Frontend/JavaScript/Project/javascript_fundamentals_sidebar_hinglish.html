1. JavaScript kya hai?

JavaScript (JS) ek programming language hai jiska use web pages ko interactive aur dynamic banane ke liye kiya jata hai. HTML page ka structure banata hai, CSS design deta hai aur JavaScript behavior aur interaction add karta hai.

History & .js

JavaScript ko Brendan Eich ne 1995 mein Netscape ke liye banaya. Shuru mein iska naam Mocha tha, baad mein LiveScript aur phir JavaScript hua. JavaScript aur Java alag languages hain. JavaScript ko standardize karne ke liye ECMAScript standard use hota hai.

.js JavaScript files ka extension hai, jaise main.js.

2. Low-level vs High-level language

Low-level

Hardware ke kareeb language, machine details zyada manage karne pad sakte hain.

10101010
MOV AX, 1

High-level

Human-readable aur abstractions ke saath comparatively aasaan language.

let total = 10 + 20;
console.log(total);

JavaScript high-level language hai.

3. Compiler vs Interpreter

Compiler

Source program ko target code mein translate karta hai, aksar execution se pehle. Example: C/C++ toolchains.

Interpreter

Runtime par program ko execute/process karta hai. Implementation details language/runtime par depend karti hain.

Modern JS engines (jaise V8) parsing, bytecode aur JIT compilation jaise techniques combine karte hain; JS engine ko sirf interpreter kehna oversimplification hai.

4. JavaScript kyu use karte hain?

  • Button click, form validation, dropdowns.

  • Testing, automation, games aur app ecosystems.

8. HTML se JavaScript link

Do files same folder mein banayein: index.html aur main.js.

index.html

<!DOCTYPE html>
<html lang="en">
<head>
 <meta charset="UTF-8">
 <meta name="viewport" content="width=device-width, initial-scale=1.0">
 <title>JS Practice</title>
</head>

 <h1>JavaScript</h1>
 <script src="./main.js"></script>
</body>
</html>

main.js

console.log("JavaScript linked successfully!");

HTML code HTML file mein, JS code JS file mein paste karein. HTML browser mein open karke Console check karein.

Script body ke end mein kyu, head mein kyu nahi?

Traditional script page parsing ko rok sakta hai jab download/execute ho. Body end par rakhne se HTML elements parse ho chuke hote hain. Modern alternative head mein defer:

<head>
 <script src="./main.js" defer></script>
</head>

defer external JS download ko HTML parsing ke saath allow karta hai aur document parse hone ke baad execute karta hai.

11. Variable kya hota hai?

Variable ek named binding hai jiske through program value ko refer kar sakta hai. Analogy: label wale box mein value rakhi hui samajh sakte hain.

Syntax

let age = 24;

let binding declare karta hai; age identifier; = assignment operator; 24 value.

Variable animation

Animation ke liye button click karein.

Ek line mein multiple variables print

let name = "Sakir";
let age = 24;
console.log("Name:", name, "| Age:", age);
// Or:
console.log(`Name: ${name}, Age: ${age}`);

12. var, let & const

Declaration

Binding ka naam define karna.

let city;

Initialization

Binding ko initial value dena.

let city = "Delhi";

Updation

Baad mein nayi value assign karna.

city = "Patna";

var

Function-scoped, block scoped nahi. Redeclare aur reassign ho sakta hai; declaration scope mein hoist hokar undefined se initialize hota hai.

var score = 10;
var score = 15; // allowed redeclaration
score = 20; // reassignment
if (true) {
 var test = "visible outside block";
}
console.log(test);

Modern code mein var avoid karte hain, kyunki block scope na hone aur redeclaration se bugs ho sakte hain.

let

Block-scoped; reassign allowed, same scope mein redeclare nahi.

let age = 24;
age = 25; // valid
// let age = 26; // SyntaxError in same scope

Value change karni ho to let.

const

Block-scoped; declaration ke waqt initialize karna zaroori, binding reassign nahi. Objects/arrays ki contents mutate ho sakti hain.

const country = "India";
// country = "Nepal"; // TypeError
const skills = ["HTML", "CSS"];
skills.push("JavaScript"); // valid

Default const; reassignment chahiye to let. var ko legacy code samajhne ke liye padhein.

Common errors

  • ReferenceError: undeclared variable, ya let/const TDZ mein use.
  • SyntaxError: same scope let/const redeclaration, const without initializer, invalid syntax.
  • TypeError: const binding reassign karna.

13. Naming Rules

  • Letters, underscore _ ya dollar $ se start.
  • Digit se start nahi kar sakte.
  • Start ke baad digits allowed.
  • Spaces/hyphens identifiers mein allowed nahi.
  • Case-sensitive: age aur Age alag.
  • Reserved keywords jaise let, if, return, class identifier ke naam nahi.
// Valid
let userName = "Sakir";
let _count = 2;
let $price = 100;
let score2 = 5;

// Invalid (commented)
// let 2score = 5;
// let user-name = "Sakir";
// let let = 10;

Reserved Keywords

Language ke reserved words special syntax/roles ke liye reserved hain. Examples: if, else, let, const, var, return, class, while, for, function, new, this.

14. Naming Conventions

Conventions style guidelines hain, strict syntax rules nahi.

camelCase

Words ke beech space nahi, next word ka first letter uppercase. Variables/functions mein common.

let firstName = "Sakir";

snake_case

Words underscore se separate. JS mein uncommon, lekin kuch projects/data context mein use.

let first_name = "Sakir";

PascalCase

Har word capital se start. Classes aur React component names mein common.

class StudentProfile {}

SCREAMING_SNAKE_CASE

Uppercase words underscore se separate; constants ke naming convention mein use.

const MAX_LIMIT = 100;

typeof null kyu object?

console.log(typeof null); // "object"

Historical JS quirk jo compatibility ke liye preserve kiya gaya. null primitive value hai, object nahi.

Non-primitive / reference types

Informal grouping: objects ek major category hain, arrays aur functions special object forms hain.

typeof operator

console.log(typeof true); // boolean
console.log(typeof undefined); // undefined
console.log(typeof 10n); // bigint
console.log(typeof Symbol()); // symbol
console.log(typeof {}); // object
console.log(typeof []); // object
console.log(typeof function(){}); // function
console.log(typeof null); // object (quirk)

16. Type Conversion

Ek type ki value ko doosre type mein convert karna. Explicit conversion programmer karta hai; implicit conversion JS operations ke dauran.

// Explicit
console.log(Number("25")); // 25
console.log(String(25)); // "25"
console.log(Boolean(1)); // true
console.log(Boolean(0)); // false

// Implicit
console.log("5" + 2); // "52"
console.log("5" - 2); // 3
Number("hello") NaN deta hai; Boolean("false") true deta hai, kyunki non-empty strings truthy hoti hain.

17. Template Literals

Backticks ` se string banate hain. ${...} interpolation se variable/expression embed kar sakte hain, multiline strings bhi.

const name = "Sakir";
const age = 24;
console.log(`My name is ${name} and my age is ${age}.`);
console.log(`4 * 2 = ${4 * 2}`);
console.log(`Next year age: ${age + 1}`);
